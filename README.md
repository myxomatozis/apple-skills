# apple-skills

Claude Code skills for building modern iOS apps with the full Apple stack (iOS 27 SDK, Swift 6, SwiftUI, SwiftData, Foundation Models).

| Skill | Covers |
|---|---|
| `ios-architecture` | MV architecture, state, navigation, DI, Swift 6 concurrency, Swift Testing |
| `ios-auth` | Passkeys, Sign in with Apple, Keychain, Face ID, account deletion, App Store rules |
| `ios-cloudkit` | CKSyncEngine, sharing, conflicts, account state, schema deployment |
| `ios-data` | URLSession, Codable, SwiftData, caching, offline, background transfers |
| `ios-intelligence` | Foundation Models, guided generation, tool calling, safety, performance |
| `ios-translations` | String Catalogs, `LocalizedStringResource`, plurals, accessibility labels |
| `ios-ui` | SwiftUI, Liquid Glass, HIG, accessibility, common pitfalls |

## Install

As a plugin:

```
/plugin marketplace add myxomatozis/apple-skills
/plugin install apple-skills@apple-skills
```

Or copy individual folders from `skills/` into `~/.claude/skills/` (all projects) or `<project>/.claude/skills/` (one project).
